## ⚙️ Getting Started

You can run this portfolio locally on your computer.

### Prerequisites

- A modern web browser.
- Git (optional).
- A code editor such as Visual Studio Code.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Jamoliddin-Kamoliddin67pro/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Open the project**

Open `index.html` directly in your browser or use the Live Server extension in VS Code.

No package installation or build process is required.
